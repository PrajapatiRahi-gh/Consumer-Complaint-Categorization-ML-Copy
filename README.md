# Consumer-Complaint-Categorization-ML
Machine learning project for consumer complaint categorization using Python, TF-IDF, Random Forest and KNN.

# Consumer Complaint Categorization Using Machine Learning

## Project Overview
This project uses machine learning techniques to categorize consumer complaints and predict whether a consumer complaint is marked as disputed.

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Scikit-learn
- TF-IDF
- Random Forest
- K-Nearest Neighbours (KNN)
- Flask
- Matplotlib and Seaborn

## Project Workflow
1. Data collection
2. Data understanding
3. Data cleaning
4. Text preprocessing
5. Feature extraction using TF-IDF
6. Model training
7. Model evaluation
8. Prediction and Flask application

## Machine Learning Algorithms
- Random Forest Classifier
- K-Nearest Neighbours Classifier

## Project Files
- Jupyter Notebook
- Python training script
- Flask application
- Requirements file
- Project visualizations
- Project documentation

## Dataset
Consumer Financial Protection Bureau (CFPB) Consumer Complaint Database:

https://www.consumerfinance.gov/data-research/consumer-complaints/

## Project Purpose
This project was developed as an internship learning project to understand data preprocessing, natural language processing and machine learning classification.

## Disclaimer
This is an educational prototype. Predictions are not legal decisions or official complaint determinations.
